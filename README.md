## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes right after launch | Reboot Windows and run the setup file again from your Downloads folder. |
| App window opens blank or black | Update your graphics driver and confirm DirectX 11 support. |
| Slow viewport while orbiting | Lower render samples or reduce the canvas size in the render panel. |
| Cannot find exported files | Check the export folder set in the save dialog, default is the project directory. |
| Palette colors look washed out | Switch the viewport to unlit mode and recheck the palette values. |
| Antivirus flags the setup file | Verify the download source and add an exclusion for the folder you saved it in. |
